# Gray Day Tracker

A Flutter app for tracking daily habits and keeping streaks going. Create trackers, monitor progress, and receive reminders.

## Requirements

- Flutter SDK compatible with Dart `^3.12.2`

## Run locally

```sh
flutter pub get
flutter run
```

## Verify

```sh
flutter analyze
flutter test
```

## Project structure

- `lib/screens/` — tracker, detail, and profile screens
- `lib/models/` — tracker data model
- `lib/services/` — local storage and notifications
- `lib/widgets/` — reusable UI components
- `assets/` — app images and icons
